## Lock bands

Declare with the Design Read. Quiet constraints override. Sketch occupancy already exists; these bands do not rewrite it.

| Band | Values | Mutates |
| --- | --- | --- |
| **layout** | `contained` / `offset` / `wild` | Containment only. Center is valid only when the Sketch already centered the mass **and** this band is `contained`. Does not pick `join=`. |
| **motion** | `still` / `fluid` / `cinematic` | Still: hover/focus only. Fluid: CSS transitions. Cinematic: claimed motion must show, and Behave named cinematic. |
| **density** | `airy` / `regular` / `dense` | Spacing tokens in [design-systems.md](design-systems.md#density-bands) |

Brand visual axes (pick one each; they are the Read, not a silent roll). **enclosure** is material (flat / nested / hairline), not Frame `join=overlap`. Nested → [material-craft.md](material-craft.md), one per section.

- **enclosure:** flat / nested / hairline
- **rhythm:** macro-sparse / editorial / modular
- **surface:** matte / hairline / ink (glass only if the scene sentence asks)
- **type:** grotesk display / serif editorial / mono accent / one family

Product UI skips these axes. Chrome stays consistent. Brand may break external consistency once; that break is the memorable detail named in the Lock.

## Brand permissions

Things product UI often cannot afford:

- Ambitious first-load motion and typographic choreography
- Single-purpose viewports (one idea per fold)
- Unexpected color strategies
- Art direction varying per section when narrative demands

Consistency of **voice** beats consistency of **treatment**.

## Copy rhythm after folds

Packet `folds=` is the page map. After those folds exist, long-form copy may repeat the **same** Success verb later in the page. That repeat is not a license for a new layout family, a features grid, or a bento. A two-fold page is complete.

On **airy** / macro-sparse brand layouts, section padding is `6rem`–`10rem` (`py-24`–`py-40`) **between** sections. First-viewport top cap stays `6rem`. The Sketch already named empty and the *break*; do not add a spatial irregularity on top. Product screens inherit this floor only on the 1–2 Pareto views named in the Lock.
