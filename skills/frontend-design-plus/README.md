# Frontend Design Plus

An agent skill for web UI: landing pages, dashboards, isolated components, HTML and CSS.

Follow [`SKILL.md`](SKILL.md). The plan in DESIGN.md is the Job, the objects, and an ASCII of the first viewport. After markup, open [`reference/critique.md`](reference/critique.md) once (Slop, Copy, Surfaces). The public terms are Job, Origin, Mode, and Signature.

## Use

Put this folder in the skills directory your harness uses, then ask for a landing, a settings page, a restyle, or a polish pass.

Start from the subject and take one aesthetic risk. Occupancy is the object's rectangles; tokens come after. If someone says "improve this" with no problem named, ask Focus and put Finish the path first. Operate uses a product recipe, not a marketing poster.

## Not this skill

No CLI detector, live variant picker, style catalog, or industry-to-palette matching. If the harness has a browser tool, Walk is a served render of header plus first viewport at 1440 and 375.
