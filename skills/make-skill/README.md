# Make skill

Writes or edits an AI agent skill so each run follows the same process. The route is the numbered list in `SKILL.md`.

The agent writes a new skill from a repeated procedure, or edits one that misses its trigger, rushes a step, mixes two jobs, or keeps a line that changes nothing. The report lists the files written and any check that did not run.

## Files

- `SKILL.md`: the procedure.
- `cases.md`: trigger requests and functional cases.
- `references/principles.md`: pointers, criteria, leading words, negation, and pruning.
- `references/mechanics.md`: frontmatter, paths, dependencies, failures, and scripts.
- `references/evaluation.md`: trials, iteration, and claimed gains.
- `references/example.md`: one request worked through to a skill.
- `references/example-router.md`: user invocation, a router, and a shared reference.
- `assets/SKILL.template.md`: a file to copy.
