# Make skill

Writes or edits an AI agent skill so each run follows the same process. The route is the numbered list in `SKILL.md`.

The agent writes a new skill from a repeated procedure, or edits one that misses its trigger, rushes a step, mixes two jobs, or keeps a line that changes nothing. The reply names the files written and any check that did not run, in the agent's own shape.

## Files

- `SKILL.md`: the procedure.
- `cases.md`: trigger requests and functional cases for this skill.
- `references/principles.md`: pointers, criteria, leading words, negation, pruning, and size.
- `references/mechanics.md`: frontmatter, paths, dependencies, failures, and scripts.
- `references/evaluation.md`: the cases file, trials, iteration, and claimed gains.
- `references/example.md`: one request worked through to a skill.
- `references/example-router.md`: user invocation, a router, and a shared reference.
- `assets/SKILL.template.md`: frontmatter, one sentence, and steps to copy.
